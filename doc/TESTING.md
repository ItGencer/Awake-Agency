# Testing

## Commands

- `npm run dev` - start the local Webpack dev server.
- `npm run build` - verify production compilation.

## Manual Checks

- [ ] Desktop layout at `1440px` width.
- [ ] Tablet layout around `768px` width.
- [ ] Mobile layout around `390px` width.
- [ ] Sticky navigation stays usable and does not cover active content.
- [ ] Mobile menu opens, closes, and closes after anchor navigation.
- [ ] Smooth scrolling works for navigation and CTA anchors.
- [ ] FAQ rows expand and collapse with correct `aria-expanded` state.
- [ ] Buttons and links have visible keyboard focus.
- [ ] External images render or degrade acceptably.
- [ ] Text does not overlap or overflow buttons, cards, or mobile containers.
